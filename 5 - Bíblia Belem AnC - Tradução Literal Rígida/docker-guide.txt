# Docker - Biblia Codices AI

Este projeto inclui configuração Docker para desenvolvimento e produção.

## Pré-requisitos

- Docker Desktop instalado
- Docker Compose instalado

## Instalação do Docker

### Windows
1. Baixar Docker Desktop: https://docker.com/get-started/
2. Executar instalador
3. Reiniciar sistema se necessário
4. Verificar instalação:
```bash
docker --version
docker-compose --version
```

### Verificação da Imagem Node.js

```bash
# Pull da imagem Node.js 24 Alpine
docker pull node:24-alpine

# Testar a imagem
docker run -it --rm --entrypoint sh node:24-alpine

# Dentro do container:
node -v  # v24.11.1
npm -v   # 11.6.2
exit
```

## Como Usar

### 1. Iniciar todos os serviços
```bash
docker-compose up -d
```

Isso irá:
- Criar container PostgreSQL (porta 5432)
- Executar schema.sql automaticamente
- Criar container do backend (porta 3000)
- Configurar rede entre os containers

### 2. Ver logs
```bash
# Todos os serviços
docker-compose logs -f

# Apenas backend
docker-compose logs -f backend

# Apenas postgres
docker-compose logs -f postgres
```

### 3. Parar serviços
```bash
docker-compose down
```

### 4. Parar e remover volumes (dados serão perdidos!)
```bash
docker-compose down -v
```

### 5. Rebuild após mudanças no código
```bash
docker-compose up -d --build
```

## Desenvolvimento Local com Docker

### Modo desenvolvimento (com hot-reload)
Criar `docker-compose.dev.yml`:
```yaml
version: '3.8'

services:
  backend:
    build:
      context: .
      dockerfile: Dockerfile.dev
    volumes:
      - ./backend:/app
      - /app/node_modules
    command: npm run dev
```

Executar:
```bash
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up
```

## Acessar Serviços

### Backend API
- URL: http://localhost:3000
- Health check: http://localhost:3000/health

### PostgreSQL
- Host: localhost
- Porta: 5432
- Usuário: postgres
- Senha: postgres
- Database: biblia_codices_ai

```bash
# Conectar ao PostgreSQL via psql
docker exec -it biblia-postgres psql -U postgres -d biblia_codices_ai
```

## Comandos Úteis

### Entrar no container
```bash
# Backend
docker exec -it biblia-backend sh

# PostgreSQL
docker exec -it biblia-postgres psql -U postgres -d biblia_codices_ai
```

### Ver containers rodando
```bash
docker ps
```

### Ver uso de recursos
```bash
docker stats
```

### Limpar containers parados
```bash
docker container prune
```

### Limpar imagens não utilizadas
```bash
docker image prune
```

### Backup do banco de dados
```bash
docker exec biblia-postgres pg_dump -U postgres biblia_codices_ai > backup.sql
```

### Restaurar backup
```bash
docker exec -i biblia-postgres psql -U postgres -d biblia_codices_ai < backup.sql
```

## Estrutura de Volumes

- `postgres_data`: Dados persistentes do PostgreSQL
- Schema SQL executado automaticamente na inicialização

## Variáveis de Ambiente

As variáveis são configuradas no `docker-compose.yml`:
- `DB_HOST=postgres` (nome do serviço)
- `DB_PORT=5432`
- `DB_USER=postgres`
- `DB_PASSWORD=postgres`
- `DB_NAME=biblia_codices_ai`
- `PORT=3000`
- `NODE_ENV=production`

## Health Checks

O serviço PostgreSQL possui health check configurado:
- Verifica se o banco está pronto a cada 10 segundos
- Backend só inicia após PostgreSQL estar saudável

## Troubleshooting

### Porta 5432 já em uso
```bash
# Parar PostgreSQL local
Stop-Service postgresql-x64-<versão>

# Ou usar porta diferente no docker-compose.yml
ports:
  - "5433:5432"
```

### Porta 3000 já em uso
```bash
# Ver processo usando a porta
netstat -ano | findstr :3000

# Matar processo
taskkill /PID <PID> /F

# Ou usar porta diferente
ports:
  - "3001:3000"
```

### Backend não conecta ao banco
- Verificar logs: `docker-compose logs postgres`
- Verificar health check: `docker ps`
- Aguardar PostgreSQL estar pronto (pode levar alguns segundos)

### Rebuild forçado
```bash
docker-compose build --no-cache
docker-compose up -d
```
