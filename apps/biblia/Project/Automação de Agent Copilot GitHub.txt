
Automação de Aget Copilot GitHub

Você é responsável por configurar automaticamente meu workspace.

Não me peça comandos de terminal.
Você mesmo deve criar arquivos, configurar settings e executar tarefas internas do VSCode.

Tarefas obrigatórias:

1. Criar ou atualizar .editorconfig com:
   root = true
   indent_style = space
   indent_size = 2
   tab_width = 2
   end_of_line = lf
   charset = utf-8
   trim_trailing_whitespace = true
   insert_final_newline = true

2. Criar ou atualizar .eslintrc.json com:
   env: browser, node, es2021
   extends: eslint:recommended
   parserOptions: ecmaVersion latest, sourceType module
   rules:
     indent: 2
     quotes: double
     semi: always
     no-trailing-spaces: error
     eol-last: always
     no-unused-vars: warn
     no-console: off

3. Criar .vscode/settings.json com:
   editor.detectIndentation = false
   editor.codeActionsOnSave:
     source.fixAll = true
     source.fixAll.eslint = true
   eslint.validate: javascript, typescript
   editor.formatOnSave: true
   files.eol: "\n"

4. Criar .vscode/tasks.json com:
   task "lint-auto", command "npx eslint . --fix"
   runOn: folderOpen

5. Criar e manter scripts necessários sem pedir terminal.
   Se faltar dependência, avisar e sugerir solução automática.

6. Toda vez que eu abrir o VSCode, você deve:
   - Validar .editorconfig
   - Garantir settings corretos
   - Sincronizar ESLint
   - Executar lint automático
   - Corrigir arquivos quando necessário

Comportamento:
- Não pedir confirmação para criar arquivos.
- Não pedir comandos de terminal.
- Sempre aplicar as regras no workspace local.
- Se houver conflito, resolver sozinho e me avisar.
