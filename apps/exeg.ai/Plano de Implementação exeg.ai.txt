Plano de Implementação: exeg.ai
Máquina de Exegese Avançada - IA especializada em "Easter Eggs" bíblicos
Resumo
Implementar o exeg.ai como uma API Python FastAPI na porta :8000 com:
Busca semântica via FAISS + SentenceTransformers
LLM local via Ollama (+ OpenAI/Anthropic opcionais)
Integração com Bible API (:3001)
Endpoints
Endpoint	Método	Descrição
/health	GET	Status dos serviços
/ask	POST	Query direta ao LLM
/find-similar	POST	Busca semântica FAISS
/explain-links	POST	Intertextualidade + LLM

Sequência de Implementação
Fase 1: Fundação
 Criar estrutura de diretórios
 src/config/settings.py - Configuração com Pydantic Settings
 src/config/constants.py - System prompt do exeg.ai

 src/models/responses.py - Modelos de response
 src/main.py - App FastAPI básico
Fase 2: Serviços Core
 src/services/bible_api_client.py - Cliente HTTP para Bible API
 src/services/embedding_service.py - SentenceTransformers
 src/services/faiss_service.py - Gerenciamento FAISS

Fase 3: LLM e Rotas
 src/services/llm_service.py - Ollama + OpenAI + Anthropic
 src/routes/health.py - Health check
 src/routes/ask.py - Query LLM
 src/routes/find_similar.py - Busca semântica
 src/routes/explain_links.py - Intertextualidade
Fase 4: Finalização
 src/services/intertextuality_service.py - Easter Eggs
 requirements.txt e requirements-gpu.txt
 .env.example
 README.md
